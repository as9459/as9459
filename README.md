      My Web Development Overview
  
      In public, I strong in building **complete web solutions from database to deployment**, including:
      - 🗂️ **Database Design & Optimization** — Normalized schemas, proper indexing, foreign key constraints
      - ⚙️ **Backend Development** — Secure PHP/MySQL applications using PDO prepared statements
      - 🎨 **Frontend Development** — Responsive RTL/LTR interfaces with clean CSS and vanilla JavaScript
      - 🔐 **Security** — Input validation, SQL injection prevention, XSS protection, secure session handling
      - 📦 **Deployment** — Production-ready configuration, `.htaccess` hardening, error logging, api Routing

      - 🏠 **Home Server Setup** — Virtualmin + Apache/Nginx on a local network
      - 🔗 **Domain Routing** — Connecting custom domains to specific virtual hosts with Port forwarding and
            DNS configuration for internet exposure
      - 🔐 **SSL/HTTPS** — Securing self-hosted sites with Let's Encrypt
